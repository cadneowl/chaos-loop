# diagnostician/scripts — developer scripts

| Script | Purpose |
|---|---|
| `diagnose-run.sh` | Diagnose a specific past experiment by ID |
| `query-loki.sh` | Run a LogQL query within an experiment's chaos window |
| `query-tempo.sh` | TraceQL search within window |
| `replay.sh` | Re-run diagnosis against a recorded fixture |
| `similarity.sh` | Find past experiments similar to a given one |
